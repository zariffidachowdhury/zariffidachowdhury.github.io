June 2026

secure-rag-guardrails

A first line of defense for LLM apps: gate the prompt, fence the retrieved documents, redact secrets from the answer. One file of standard-library Python, and every decision comes back with the rules that fired.

Built in June 2026 as a study of the OWASP Top 10 for LLM applications. Heuristic on purpose: a fast, auditable gate, not a classifier.

Caveats

Pattern matching is evadable by a paraphrase or an encoding. In the demo above, the poisoned document's own instruction is caught only because it also carried a chat-template token, which is why the fence, not the rules, is the real defense. The redaction patterns over-match on long digit runs. It reduces risk, it does not remove it.

The round function here is a simple demo one, not the ZFC one. The structure is the point: F never has to be invertible, because the swap makes the whole thing invertible. The same rounds run backwards decrypt.
